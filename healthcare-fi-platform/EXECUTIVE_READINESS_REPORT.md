## Key Findings

### Executive Center is the strongest page
Shows KPIs, alerts, forecasts, risks, and a one-click briefing generator. This is the "single pane of glass" an executive needs.

### Knowledge Graph is not executive-ready
Shows UUIDs instead of entity names. Requires Node IDs for search. Basic SVG circles. Needs complete redesign for executive use.

### Forecasting needs a simplified mode
Currently requires choosing Prophet/ARIMA/XGBoost and entering JSON parameters. An executive needs "Show me next quarter's revenue" — not model configuration.

### Strategic Planning input needs pre-population
Blank key-value fields for assumptions. Should pre-populate common healthcare metrics (revenue growth, occupancy, cost inflation).
